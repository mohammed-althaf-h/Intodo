## Problem Statement
Corporate workers face strict restrictions on work laptops: endpoint security (EDR/XDR like CrowdStrike, Defender ATP, SentinelOne) that flags unauthorized installers or invasive system hooks, locked-down admin privileges, and strict corporate proxy firewalls. At the same time, users juggle work tasks and personal tasks with no clean way to isolate them, while needing a frictionless way for colleagues to delegate/assign tasks directly into their pending work queue without context switching.

## What Makes This Cool
- **Floating Spotlight & Island Desktop Widget**: A sleek, hoverable, always-on-top or hotkey-triggered island on Windows desktop that seamlessly collapses and expands with fluid micro-animations.
- **100% EDR/XDR-Safe & Zero-Admin Portable Executable**: A standalone ~3MB portable binary (via Tauri v2 leveraging native Windows WebView2) that runs purely in user-space (`%LocalAppData%`) with zero registry tampering, zero global keyboard hooks, and zero network heuristics anomalies. If binaries are blocked, it runs as a 100% capable PWA in any browser.
- **Dual Vault Architecture (Work vs. Personal)**: Distinct visual modes and separate local vaults with isolated client-side encryption keys.
- **Zero-Knowledge Collaborative Delegation**: Teammates can push pending action items into your "Work Queue" using End-to-End Encrypted (E2EE) room codes over standard HTTPS/WSS (port 443), passing cleanly through enterprise corporate proxies with zero alerts.

## Constraints
1. **Zero-Privilege Windows Execution**: Must never require admin UAC elevation or installer permissions.
2. **EDR/XDR Clean Bill of Health**: No suspicious process injection, no global DLL hooks, standard signed/clean PE structure.
3. **Cross-Platform Compatibility**: Single codebase running on Windows (Tauri v2), iOS (PWA / Capacitor / Web), Android (PWA / Capacitor / Web).
4. **Offline-First Resilience**: Full offline standalone functionality via local IndexedDB / SQLite with instant UI updates and optional encrypted cloud relay.

## Premises
1. **Enterprise Safety**: Portable user-space architecture avoiding security software false positives.
2. **Zero-Knowledge Collaboration**: Standard HTTPS/WSS (443) E2EE room relays avoid firewall blocks and proxy inspection data leaks.
3. **Strict Profile Isolation**: Work and Personal profiles use independent local storage partitions and cryptographic keys.
4. **Web-First Multiplatform Core**: High-velocity single codebase with native-feel desktop wrapper.

## Approaches Considered

### Approach A: Flutter Native Multi-Platform
- **Summary**: Native Dart/C++ application targeting Windows, iOS, and Android.
- **Effort**: Medium-High | Risk: Low
- **Pros**: Pixel-perfect native UI, compiled native binaries.
- **Cons**: Larger binary size (~30MB+), requires complex platform toolchains for desktop and mobile builds.

### Approach B: Web-First PWA + Tauri v2 Desktop (Chosen Approach)
- **Summary**: Modern TypeScript web application running in a ~3MB portable Tauri v2 wrapper on Windows (using native WebView2) and PWA/Capacitor on iOS & Android.
- **Effort**: Low-Medium | Risk: Very Low
- **Pros**: Rapid development, ultra-small binary footprint, runs in browser if company policies block external EXEs, zero admin rights needed.
- **Cons**: Uses system WebView2 runtime on Windows.

### Approach C: Local-First CRDT (Yjs/Automerge) Engine
- **Summary**: Decentralized peer-to-peer sync engine with local state reconciliation.
- **Effort**: High | Risk: Medium
- **Pros**: Flawless offline multi-device merging.
- **Cons**: Higher sync schema complexity and maintenance burden.

## Recommended Approach
**Approach B (Web-First PWA + Tauri v2 Desktop)**. It delivers the highest enterprise resilience, lowest deployment friction (zero admin, 3MB portable executable, runs in browser as fallback), rich floating widget UI capabilities, and 100% cross-platform coverage for iOS, Android, and Windows.

## Open Questions
- **Default Room Relay Provider**: Lightweight Cloudflare Worker vs. open-source WebSocket relay server.
- **Global Hotkey preference**: Customizable local hotkey (e.g., `Alt + Space` or `Ctrl + Shift + T`) when the window is focused vs. tray click.

## Success Criteria
1. Windows standalone portable `.exe` launches in under 500ms without admin prompt and zero antivirus/EDR flags.
2. Personal and Corporate tasks strictly segregated with zero cross-contamination.
3. Colleague can open an invite link/code and submit a task to the user's pending queue over E2EE WebSockets.
4. Desktop floating island widget smoothly expands/collapses and supports quick task capture.
5. Works seamlessly on mobile (iOS & Android) via responsive PWA / mobile package.

## Distribution Plan
- **Windows**: Single portable `.exe` release via GitHub Releases (zip / direct download).
- **Web / PWA**: Hosted on Cloudflare Pages / Vercel with offline service worker.
- **Mobile**: PWA install prompt / optional Capacitor iOS & Android builds.
- **CI/CD**: GitHub Actions pipeline to automate testing, web build, and Tauri portable artifact release.

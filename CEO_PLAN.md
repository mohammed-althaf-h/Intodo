## 1. Executive Summary & Strategic Vision

**Intodo** is an ultra-resilient, multi-platform task management system built specifically to thrive under strict enterprise constraints (zero admin privileges, active EDR/XDR monitoring like CrowdStrike and Defender ATP, and restrictive corporate SSL inspection proxies) while delivering personal/work profile isolation and peer task delegation.

### The 10-Star Product Experience
1. **Zero Resistance Deployment**: Single-file ~3MB portable executable running in user space (`%LocalAppData%`) with zero registry changes and zero driver hooks. Works out-of-the-box on locked-down Windows laptops, and also runs anywhere as a zero-install Progressive Web App (PWA) on iOS and Android.
2. **Ambient Desktop Widget (Spotlight / Floating Island)**: A smooth, dockable floating pill that hovers on your screen or activates with a hotkey, enabling instant task capture and focus without interrupting your workflow.
3. **Dual Vault Isolation (Work vs. Personal)**: Distinct visual environments with separate local storage partitions and isolated client-side encryption keys.
4. **Zero-Knowledge Task Delegation**: Colleagues can push tasks into your "Pending from Others" inbox via End-to-End Encrypted (E2EE) WebSockets over port 443, appearing as standard HTTPS traffic with zero corporate firewall alarms.

### Data Flow Paths

#### 1. Task Creation & Local Persistence (Happy Path)
1. User types task in Full View or Floating Island.
2. State manager validates input, creates task object with UUID and timestamp.
3. Task is written to active profile vault in IndexedDB.
4. UI updates instantly (< 16ms, 60fps).

#### 2. Collaborative Task Delegation Flow
1. User creates a Delegation Room / Link (`room_id` + encryption secret `key`).
2. Colleague opens Delegation Portal in browser, enters task description, priority, and deadline.
3. Colleague's browser encrypts the task payload locally using AES-256-GCM before transmission.
4. Encrypted ciphertext is relayed via standard WebSocket (`/ws/room/{room_id}`).
5. User's client receives ciphertext, decrypts locally, and places task in "Incoming Pending Work" queue with a subtle notification badge.

#### 3. Shadow Paths & Fallback Behavior
- **Nil/Empty Input**: Client-side validator rejects empty strings with visual micro-shake; no state mutation.
- **Offline / Network Interruption**: App operates 100% offline. Outbound sync events queue in local IndexedDB outbox and auto-flush upon reconnection.
- **Corrupt Vault State**: Automatic schema migration and isolated fallback recovery without data loss.

## 3. Enterprise Safety & EDR Compliance Architecture

| Risk Factor | Legacy Desktop Apps | Intodo Architecture | EDR/XDR Impact |
| :--- | :--- | :--- | :--- |
| **Installation** | MSI / EXE requiring UAC Admin | User-space portable binary / PWA | **Zero alerts**: No UAC prompt, no system folder writes |
| **System Hooks** | Global keyboard/mouse DLL injection | Standard application-focused keyboard shortcuts | **Zero alerts**: No process tampering or memory injection |
| **Network Traffic** | Non-standard P2P ports (e.g. 8080, 5000) | Standard TLS 1.3 over port 443 | **Zero alerts**: Standard HTTPS web traffic |
| **Data Privacy** | Plaintext cloud syncing | Client-side AES-256-GCM zero-knowledge encryption | **Zero risk**: Corporate proxies cannot read private contents |

## 4. Error & Rescue Map

| Method / Component | Potential Failure | Handling & User Experience |
| :--- | :--- | :--- |
| `VaultStorage.save()` | Quota exceeded / Storage blocked | Fallback to in-memory store + visible warning banner prompting JSON backup export |
| `CryptoEngine.encrypt()` | Invalid key or WebCrypto failure | Abort sync operation, preserve unencrypted local state, notify user safely |
| `WebSocketRelay.connect()` | Network offline / Proxy block | Seamlessly transition to Offline Standalone mode; retry with exponential backoff |
| `TaskDelegator.receive()` | Decryption failed (wrong room key) | Log cryptographic mismatch; drop packet safely without crashing state |

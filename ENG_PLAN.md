## 3. Cryptographic & Security Specification

1. **Algorithm**: AES-256-GCM (Authenticated Encryption with Associated Data).
2. **Key Storage**: Local key stored in browser `crypto.subtle` exportable format in isolated secure storage.
3. **Delegation Room Key**: 256-bit room secret shared via URL hash fragment (e.g., `/#/delegate?room=xyz#key=secret`). The encryption key is in the URL hash, meaning it is **never** sent to the web server or proxy in the HTTP request headers.
4. **Network Traffic**: Strict TLS 1.3 over standard HTTPS/WSS (port 443). Zero anomalous ports or raw socket protocols.

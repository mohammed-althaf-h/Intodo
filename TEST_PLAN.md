## Affected Pages & Interfaces
- `/` — Full Workspace View (Work & Personal modes, task lists, inboxes, filters, quick-capture)
- `/widget` — Ambient Floating Island / Spotlight Hover Widget (dock/expand/hotkey)
- `/delegate/:roomId` — Zero-Knowledge Delegation Portal (public page for colleagues to drop tasks)

## Key Interactions to Verify
1. **Profile Vault Isolation**: Create tasks in Work Profile (e.g. "Draft Q3 Report"). Switch to Personal Profile (Emerald theme). Verify Work tasks do NOT leak into Personal list and vice versa.
2. **Instant Task Capture**: Add task with deadline & tags via quick-capture input (both in Full View and Floating Island widget). Verify immediate (<16ms) optimistic UI update.
3. **E2EE Task Delegation**:
   - Host generates a Delegation Room code.
   - Colleague submits task "Review PR #42" from Delegation Portal.
   - Verify task is encrypted client-side, relayed over WSS, decrypted by Host, and appears in "Pending from Others" inbox with notification badge.
4. **Offline Resilience**: Disconnect network. Add/complete tasks. Reconnect network. Verify all operations succeed and sync queues flush cleanly.
5. **Encrypted Vault Export/Import**: Export vault as encrypted JSON backup. Wipe local storage. Re-import backup with passphrase. Verify full task state recovery.

## Edge Cases
- **Empty / Nil Input**: Empty or whitespace-only task submissions shake input and are rejected with zero state mutation.
- **Corrupt Ciphertext**: Sending corrupted or tampered ciphertext to the Delegation WebSocket is safely dropped with an error toast; host state does not crash.
- **Rapid Profile Toggling**: Switching profiles back and forth quickly does not cause race conditions in active store state.
- **Storage Quota / Incognito**: If IndexedDB / localStorage is unavailable or blocked, falls back gracefully to in-memory store with export prompt.

## Critical Paths
- App cold start in < 500ms
- Local task mutation & encryption roundtrip
- Zero-knowledge delegation handshake and reception
